# p5.js sketches

```sh
apn --html examples/browser/p5-sketch.apn p5-sketch.html
open p5-sketch.html
```

Import `p5` and set `main` to `sketch` with a record of callbacks. The browser
loads [p5.js 2.3.3](https://github.com/processing/p5.js/releases/tag/v2.3.3)
from jsDelivr; these pages need network access to load it. Ordinary HTML apps
still run without it. Running the APN source in the terminal only defines the
sketch.

```apn
std <- import "std"
use std.p5
clicks = Mutable 0
setup (p : Sketch) = {
    p.createCanvas 640 360
    p.describe "An animated peach circle. Click to change its size."
    p.noStroke
}
draw (p : Sketch) = {
    p.background "#232634"
    p.fill "#ef9f76"
    p.circle (320 + 160 * sin (p.frameCount / 40)) 180 (60 + clicks * 10)
    p.fill "#c6d0f5"
    p.textSize 18
    p.text ("Clicks: " ++ to String clicks) 20 30
}
mousePressed _ = {
    set clicks (clicks + 1)
    return False
}
main = sketch [setup = setup, draw = draw, mousePressed = mousePressed]
```

`examples/p5js` recreates all of [p5.js's examples](https://p5js.org/examples/);
`apn --site examples/p5js OUTPUT` builds them as a
[site with an editor](browser-html.md#examples-site-and-editor).

## Callbacks

Callbacks receive the running sketch, `p`, and run in p5's
[instance mode](https://p5js.org/reference/p5/p5/). `setup` runs once and
`draw` each frame; the others are optional: `mousePressed`, `mouseReleased`,
`mouseClicked`, `mouseMoved`, `mouseDragged`, `doubleClicked`, `mouseWheel`,
`keyPressed`, `keyReleased`, `keyTyped`, `windowResized`, `touchStarted`,
`touchMoved`, `touchEnded`, `deviceMoved`, `deviceTurned` and `deviceShaken`.
Returning `False` from an event callback asks p5 to suppress the event's
default. An APN error stops the drawing loop and appears on the page. Keep a
sketch's state in `Mutable` cells.

## The sketch, `(p : Sketch)`

`Sketch` is the type of `p`: a parameter `(p : Sketch)` is checked against it.
Its properties are typed: numbers (`width`, `height`, `windowWidth`,
`windowHeight`, `displayWidth`, `displayHeight`, `mouseX`, `mouseY`,
`pmouseX`, `pmouseY`, `keyCode`, `frameCount`, `deltaTime`, the
accelerations and rotations, `PI`, `TWO_PI`, `HALF_PI`, `QUARTER_PI`),
`mouseIsPressed` and `keyIsPressed` (Bool), and `key` and `code` (String).
A property is read where a callback first uses it, so `p.width` after
`p.createCanvas` is the new width. p5's constants (`CENTER`, `HSB`, `WEBGL`,
`CLOSE`, `LEFT_ARROW`, ...) are Dynamic.

Methods are curried with p5's basic arity: `p.circle x y diameter`. One that
takes nothing is an action field: `p.noStroke`, `p.push`, `p.pop`,
`p.noLoop`. Their arguments are Dynamic (p5's take many kinds: a color is a
number, a string or a list), checked as they run. Most yield `[]`; those that
compute a value (`random`, `noise`, `millis`, `color`, `lerpColor`, `red`,
..., `textWidth`, `get`, `getItem`, `keyIsDown`, `isLooping`) yield it as
Dynamic: bind it with `<-` and convert it where a type is needed
(`x <- p.random 0 10; set position (x : Float)`). For p5's other overloads,
`p.call` takes a method's name and its arguments, and yields p5's result:

```apn
p.call "fill" [255,100,50,200]
p.call "createCanvas" [400,400,p.WEBGL]
p.call "vertex" [x,y,z]
rate <- p.call "frameRate" []
```

`p.call` reaches the same methods as the fields, not arbitrary JavaScript.
`p.prompt message` asks the visitor for text (`""` when cancelled);
`p.getItem` and `p.storeItem` keep values in the browser, where the page may.

## Objects

What p5 makes or loads (an image, a font, a model, a video, a graphic, a
shader, a framebuffer) is a value describing it:

```apn
font = loadFont "assets/SourceSansPro-Regular.otf"
graphic = createGraphics 405 250
```

Each sketch makes (or loads) an object the first time it uses it and keeps
it: a top-level description is one object. A sketch's `preload` lists the
files to load before `setup`, as p5's `async setup` awaits them:
`sketch [preload = [font], setup = setup, draw = draw]`. The makers are
`loadImage`, `loadFont`, `loadModel`, `createImage`, `createGraphics`,
`createVideo` (a list of sources, the first the browser plays),
`createAudio`, `createCapture` (the webcam), `createShader`,
`createFilterShader`, `createFramebuffer`, `buildGeometry` (its function
draws with the sketch's `p`), `baseFilterShader`, `baseColorShader`,
`baseMaterialShader`, and `modify hooks shader`. A new description is a new
object; a `Mutable` cell can hold one and take another:
`set snake (buildGeometry drawSnake)`.

An object has every method a sketch has, which draw on it (`graphic.ellipse x
y 60 60`), and its own (`video.loop`, `video.hide`, `image.mask other`,
`shader.setUniform "time" t`, `layer.begin`, `geometry.normalize`, ...); one
its object lacks fails when called. Its properties `width`, `height`,
`color`, `depth` and `duration` are actions: `w <- video.width`. A file a
program names this way is bundled with it (see
[Browser HTML](browser-html.md)).

## Shaders in APN

`createShader vertex fragment` and `createFilterShader fragment` take GLSL
source. As [p5.strands](https://beta.p5js.org/tutorials/intro-to-p5-strands/)
writes shaders in JavaScript, `buildFilterShader`, `buildColorShader` and
`buildMaterialShader` take hooks written in APN, on values of the `glsl`
module: arithmetic, `sin`, `cos`, `floor`, `max`, ... on them writes GLSL
(numbers become floats and lists vectors), with `fract`, `distance`, `mix`,
`swizzle "xy" v`, `getTexture sampler point` and `vec [x,y]`.

```apn
std <- import "std"
use std.[glsl,p5]
wiggle inputs = {
    [x,y,z] = map (axis -> swizzle axis inputs.position) ["x","y","z"]
    [position = vec [x, y + 20 * sin (MkGlsl "time" * 0.01 + y * 0.1), z]]
}
wiggleShader = buildColorShader [time = ["float", (p : Sketch) -> p.millis]] [objectInputs = wiggle]
```

The first argument names the uniforms, each with its GLSL type and its value
each frame (a function of the sketch); a hook reads one by name. A filter's
hook gets `texCoord`, `canvasSize`, `texelSize` and `canvasContent` and
gives the pixel's color. The others' hooks, by name (`objectInputs`,
`worldInputs`, `cameraInputs`, a material's `pixelInputs`), get p5's inputs
(`position`, `normal`, `texCoord`, `color`; a pixel's also `ambientLight`,
`specularMaterial`, ...) and give the ones they change.

## Calculations

p5's calculations that read nothing from a sketch are APN functions: `remap`
(p5's `map`), `lerp`, `constrain` and `dist`. Vectors are lists, which `+`,
`-`, `*` and `/` combine element by element; `mag`, `normalize`, `setMag`,
`limit`, `heading` and `fromAngle` complete p5.Vector. Angles are radians;
`number.degrees` converts degrees.

## Numbers and values

Numbers cross into JavaScript as they are drawn. Fractions become
floating-point numbers; an integer outside JavaScript's safe range needs an
explicit `inexact`. Lists become arrays, and records and HashMaps objects;
p5's results come back as APN values, and its objects (a color, a
framebuffer's texture) as records with the same methods.

## Sketches in views

`canvas callbacks` is a sketch inside an HTML view, as a node of an
[element program](browser-html.md#elements-commands-and-subscriptions). It
starts once and keeps drawing; each render gives it the view's newest
callbacks, so `draw` can read the model (a sketch that does not loop draws
once more with them), and `p.send msg` sends a message to `update`:

```apn
std <- import "std"
use std.[html,p5]
browser <- import "std/browser"

Msg = | TimeDelta Number

update (TimeDelta dt) angle = [angle + dt / 5000, browser.none]

view angle = canvas [setup = setup, draw = draw angle]

setup (p : Sketch) = p.call "createCanvas" [400,400,p.WEBGL]

draw angle (p : Sketch) = {
    p.background "white"
    p.rotateY angle
    p.normalMaterial
    p.box 100 100 100
}

main = browser.element [
    init = [0,browser.none]
    update = update
    subscriptions = _ -> browser.onAnimationFrameDelta TimeDelta
    view = view
]
```

Forms, sliders and buttons beside a canvas are such views:
`examples/p5js/materials.apn`, `noise.apn` and `json.apn` are three.
`examples/elm` draws Elm's WebGL examples this way.
