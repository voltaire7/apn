# p5.js sketches

```sh
apn --html examples/browser/p5-sketch.apn p5-sketch.html
open p5-sketch.html
```

Import `p5` explicitly and set `main` to `p5.sketch` with a callback record.
The browser loads [p5.js 1.11.11](https://github.com/processing/p5.js/releases/tag/v1.11.11)
from jsDelivr; these pages need network access to load that dependency.
Ordinary HTML sandbox apps still run without it. Running the APN source directly
in the terminal only defines the sketch.

```apn
p5 = import "p5"
clicks = Mutable 0
setup p = {
    p.createCanvas 640 360
    p.describe "An animated peach circle. Click to change its size."
    p.noStroke ()
}
draw p = {
    p.background "#232634"
    p.fill "#ef9f76"
    p.circle (320 + 160 * sin (p.frameCount / 40)) 180 (60 + clicks * 10)
    p.fill "#c6d0f5"
    p.textSize 18
    p.text ("Clicks: " ++ toString clicks) 20 30
}
mousePressed p = {
    set clicks $ (clicks + 1)
    return false
}
main = p5.sketch [setup: setup, draw: draw, mousePressed: mousePressed]

```

Callbacks receive a `p` record and run in p5's
[instance mode](https://p5js.org/reference/p5/p5/).
`setup` runs once, `draw` runs each frame. Mouse, keyboard, touch, and resize
callbacks are optional. Returning `false` from an event callback requests p5's
normal default-event suppression. An APN callback error stops the drawing loop
and appears on the page. Use `Mutable` cells for persistent sketch state.

The supported callbacks are `setup`, `draw`, `mousePressed`, `mouseReleased`,
`mouseClicked`, `mouseMoved`, `mouseDragged`, `doubleClicked`, `keyPressed`,
`keyReleased`, `keyTyped`, `windowResized`, `touchStarted`, `touchMoved`, and
`touchEnded`.

Drawing functions are curried, e.g. `p.circle x y diameter`. Methods with no
arguments take []: `p.noStroke []`, `p.push []`, `p.pop []`, `p.noLoop []`.
For optional arguments and overloads use a list:

```apn
p.call "fill" [255,100,50,200]
p.call "rect" [10,20,100,50,8]
p.call "endShape" [p.CLOSE]
p.call "random" [10,20]
```

`p.call` supports the same method set as the named functions, not arbitrary JavaScript.

| Area | Functions |
| --- | --- |
| Canvas | createCanvas, resizeCanvas, background, clear, pixelDensity, describe |
| Style | fill, noFill, stroke, noStroke, strokeWeight, colorMode |
| Shapes | circle, ellipse, rect, square, line, point, triangle, quad, arc, bezier |
| Paths | beginShape, vertex, endShape |
| Transforms | push, pop, translate, rotate, scale, rectMode, ellipseMode, angleMode |
| Text | text, textSize, textAlign, textFont |
| Timing | frameRate, noLoop, loop, redraw, millis |
| Randomness | random, randomSeed, noise, noiseSeed |

Convenience functions use the basic arity shown by their p5 equivalents;
`fill`, `stroke`, and `background` take one color (a string, grayscale number,
or component list); `random` takes one upper bound and `noise` one coordinate.
`textAlign`, `colorMode`, and `scale` take one argument. `createCanvas` takes
width and height. Use `p.call` for other overloads.

Properties are snapshots at the start of each callback: `width`, `height`,
`windowWidth`, `windowHeight`, `mouseX`, `mouseY`, `pmouseX`, `pmouseY`,
`mouseIsPressed`, `mouseButton`, `key`, `keyCode`, `keyIsPressed`, `frameCount`,
and `deltaTime`. Do not retain the callback's `p` record to read later input.
Constants include `PI`, `TWO_PI`, `HALF_PI`, `QUARTER_PI`, `CENTER`, `CORNER`,
`CORNERS`, `RADIUS`, `LEFT`, `RIGHT`, `TOP`, `BOTTOM`, `BASELINE`, `CLOSE`,
`RGB`, `HSB`, `HSL`, `DEGREES`, `RADIANS`, `P2D`, and `WEBGL`.

Numbers cross into JavaScript for drawing. Fractions become floating-point
numbers; integers outside JavaScript's safe range require an explicit `inexact` conversion.
Primitive return values are converted back into APN. Renderer objects and void
results become []. This first binding covers synchronous drawing and input:
image/font loading, preload, media, sound, pixels, vectors, and object handles
are not exposed. One `main` starts one sketch; HTML and p5 cannot yet be composed
in the same application through this API.

Record shorthand avoids repeating callback names: when `setup`, `draw`, and
`mousePressed` are in scope, `p5.sketch [.setup, .draw, .mousePressed]` means
`p5.sketch [setup: setup, draw: draw, mousePressed: mousePressed]`.
